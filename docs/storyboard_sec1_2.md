## Sec 1. 서론

**흐름 원칙**: 깔때기(funnel) 구조 — 사회적 문제(영양 불균형) → 현재 도구의 한계(사용 피로감) → 이 연구의 답(KG+MOO) → 논문 구성

**소절 역할 분리**
- 1.1: "왜 이 문제가 중요한가" — 영양 불균형이라는 사회적 배경
- 1.2: "기존 서비스가 왜 이 문제를 해결 못 하는가" — 사용 피로감
- 1.3: "이 연구는 무엇을 제안하는가" — 목적·기여·학술 차별점
- 1.4: 논문 구성 안내

### 1.1 연구 배경

**주장**: 현대인의 영양 불균형은 만성질환의 주요 위험 요인으로, 균형 잡힌 식단 자동화의 사회적 필요성이 높다.

**핵심 논리 흐름**:
1. 현대인의 영양 섭취 실태 — 국민건강영양조사(KNHANES 2023, 질병관리청)에 따르면 한국 성인의 영양소 불균형(나트륨 과다, 칼슘·식이섬유 부족)이 지속적으로 보고되고 있다.
2. 불균형 식습관의 건강 영향 — 2020 한국인 영양소 섭취기준(보건복지부 × 한국영양학회)은 부적절한 영양 섭취가 비만·당뇨·고혈압 등 만성질환의 주요 위험 요인임을 명시한다.
3. 균형 잡힌 식단 자동화의 필요성 — 개인 영양 목표에 맞는 식단을 자동으로 추천하는 시스템이 만성질환 예방과 일상 식사 관리에 효과적일 수 있다.

**그림**: 없음 — 국민 영양 실태를 수치로 인용하는 서술만으로 충분.

**서술 주의**:
- 한국 맥락에 맞는 한국 공식 통계·기준을 근거로 사용 (Wansink 2007 사용 금지)
- 영양 불균형 → 만성질환 연결의 인과관계를 과장하지 말고, "위험 요인 중 하나"로 표현

### 1.2 기존 서비스의 한계

**주장**: 현재 식단 기록·추천 서비스는 사용자가 매번 직접 입력하고 판단해야 하는 구조로, 지속적 사용을 어렵게 만든다. 칼로리·영양소·가격·개인 선호를 동시에 자동화하는 서비스는 존재하지 않는다.

**핵심 논리 흐름**:
1. 현재 서비스의 수동 입력 문제 — MyFitnessPal, Samsung Health 등 기존 식단 관리 앱은 사용자가 섭취한 음식을 매번 검색·입력해야 하며, 다음 식사를 직접 선택·판단해야 하는 인지적 부담이 크다.
2. 추천 기능의 단순성 — 기존 서비스의 식단 추천은 칼로리 단일 기준이거나 영양소 범주 체크 수준으로, 가격·개인 선호·식문화를 동시에 고려하는 다목적 추천은 제공되지 않는다.
3. 개인화의 한계 — 사용자 이력이 충분하지 않은 초기 상태(cold start)에서 개인 선호를 반영한 추천이 사실상 불가능하다.

**그림**: 없음 — 텍스트 서술로 충분. 기존 앱의 스크린샷은 저작권 문제로 생략.

**서술 주의**:
- 특정 서비스 비방이 아니라 구조적 한계를 기술 (예: "검색 기반 수동 입력 방식은 …")
- 학술적 선행연구의 한계(MealRec의 서양 DB 등)는 1.2가 아닌 1.3의 차별점으로 이동

### 1.3 연구 목적 및 기여

**주장**: 본 연구는 한국 식품 DB 기반 지식 그래프(KG)와 4목적 R-NSGA-II를 결합하여, 칼로리·영양소·가격·개인 선호도를 동시에 최적화하는 일일 식단 자동 추천 시스템을 제안한다.

**핵심 논리 흐름**:

**연구 목적 선언**: 사용자가 별도 입력 없이, 칼로리·영양소 균형·예산·개인 선호를 동시에 충족하는 일일 식단 Pareto 최적해 집합을 자동으로 생성한다.

**기여 1 — 데이터**:  
식약처(MFDS) 2,524건 + 국내 프랜차이즈 871건 = 3,358건의 한국 특화 식품 DB(food_master) 구축.  
LLM 기반 5-class 식사 카테고리(MAIN/SOUP/SIDE/DRINK/SNACK) + 7-class 식문화 자동 분류 파이프라인 설계.

**기여 2 — 알고리즘**:  
4목적 R-NSGA-II 제안: f1(칼로리), f2(영양소 비율), f3(가격), f4(KG 기반 선호도).  
G1(NSGA-II) / G2(R-NSGA-II) / G3(R-NSGA-II+KG) 3단계 ablation 설계로 각 구성요소 기여를 독립 검증.

**기여 3 — KG 개인화**:  
시간 감쇠 함수(λ=0.5)로 반복 추천을 억제하고, 식문화 기반 KG 초기화로 cold start 문제를 해소.  
7일 시뮬레이션에서 f4 83% 감소, 중복률 0.0(Day 1~5) 확인.

**기존 학술 연구 대비 차별점**:
- MealRec(arXiv:2205.12133) / MealRec+(SIGIR 2024, DOI:10.1145/3626772.3657857): KG 기반 식사 추천 선행연구이나 서양식 DB 기반, 가격·한국 식문화 미반영

- 기존 MOO 식단 연구: 단일 또는 2목적 최적화, KG 개인화 미결합

**그림**: `fig0_system_overview.png`
- 배치 위치: 기여 항목 열거 직후 또는 직전 — 시스템 전체 구조를 한눈에 파악

### 2.1 다목적 최적화 (MOO)

**주장**: 복수의 상충하는 목표를 단일 스칼라로 합산하지 않고, 목표 공간에서 지배 불가능한 해 집합(Pareto Front)을 탐색하는 다목적 최적화가 식단 추천에 적합하다.

**핵심 논리 흐름**:
1. 단일 목적 한계 — 칼로리 최소화만 추구하면 영양소 불균형이 발생하고, 가중합 방식은 가중치 설정이 주관적이며 목표 간 상충관계(trade-off)를 표현하지 못한다.
2. Pareto 최적 개념 — "다른 목적을 악화시키지 않고서는 어떤 목적도 더 개선할 수 없는 해의 집합"(Pareto Front)을 구하는 것이 MOO의 목표다. 의사결정자는 이 집합에서 상황에 맞는 해를 선택할 수 있다.
3. 식단 추천에서의 적용 이유 — 칼로리 최소화와 가격 최소화는 상충할 수 있다(저칼로리 건강식은 비쌀 수 있음). 영양 균형과 개인 선호도도 trade-off 관계에 있다. 이를 Pareto Front로 탐색하면 사용자의 다양한 우선순위를 반영할 수 있다.

**Forward-reference**: 본 연구에서는 4개 목적함수(f1~f4)를 정의하고(Sec 4.2), R-NSGA-II로 Pareto Front를 탐색한다(Sec 2.3, Sec 4.3).

**그림**: 없음 — 표준 개념이므로 텍스트 서술로 충분.

### 2.2 NSGA-II

**주장**: NSGA-II(Deb et al., 2002)는 비지배 정렬과 혼잡도 거리를 결합한 대표적 진화형 다목적 최적화 알고리즘으로, 본 연구의 베이스라인(G1)으로 사용된다.

**핵심 논리 흐름**:
1. 핵심 아이디어 — 비지배 정렬(Non-dominated Sorting)로 해집단을 Front 1(최우수), Front 2, … 로 계층화하고, 같은 Front 내에서는 혼잡도 거리(Crowding Distance)가 높은 해(목적 공간에서 이웃이 적은 해)를 우선 선택해 다양성을 확보한다.
2. 연산 과정 — 선택(토너먼트) → SBX 교차(p=0.9) → PM 변이(p=1/n) → 비지배 정렬 → 혼잡도 거리 정렬 → 다음 세대 구성.
3. 본 연구 G1 파라미터 — population=200, generation=200, 3목적(f1, f2, f3). 참조점 없음.

**Forward-reference**: NSGA-II는 참조점 없이 Pareto Front 전체를 균등 탐색한다. 특정 선호 영역에 해를 집중시키는 확장이 2.3의 R-NSGA-II에서 소개된다.

**그림**: 없음 — Deb et al.(2002) 인용으로 충분.

**인용**: Deb, K., Pratap, A., Agarwal, S., & Meyarivan, T. (2002). A fast and elitist multiobjective genetic algorithm: NSGA-II. *IEEE Transactions on Evolutionary Computation*, 6(2), 182-197.

---

### 2.3 R-NSGA-II

**주장**: R-NSGA-II(Deb & Sundar, 2006)는 NSGA-II에 참조점(reference point)을 도입하여 Pareto Front의 특정 선호 영역에 해를 집중시키는 알고리즘으로, 본 연구의 G2(3목적)와 G3(4목적)의 기반이다.

**핵심 논리 흐름**:
1. NSGA-II의 한계 — 표준 NSGA-II는 Pareto Front 전체를 균등하게 탐색하지만, 사용자가 특정 목적 우선순위(예: 영양소 균형 최우선)를 가질 경우 해당 영역의 해를 충분히 탐색하지 못할 수 있다.
2. 참조점 도입 — 사용자 지정 참조점(이상적 목적값 벡터)에 가까운 해를 우선적으로 탐색하도록 혼잡도 거리 계산을 수정. 이를 통해 참조점 근방의 해가 선택 압력을 받아 더 세밀하게 탐색된다.
3. 본 연구 적용:
   - G2: 참조점 `[[0,0,0]]` — f1·f2·f3 이상점에 집중하여 참조점 효과 독립 검증
   - G3: 참조점 `[[0,0,0,0], [0.1,0.1,0.1,0]]` — 이상점과 선호 우선점을 동시에 탐색하여 KG 개인화와 영양·가격 균형을 모두 고려

**Forward-reference**: G1/G2/G3의 참조점 구성과 전체 파라미터는 Sec 4.3에서 상세히 기술한다.

**그림**: 없음 — 참조점 효과는 실험 결과(fig1, fig3)에서 시각적으로 입증되므로, 이론 소절에서는 텍스트만으로 충분.

**인용**: Deb, K., & Sundar, J. (2006). Reference point based multi-objective optimization using evolutionary algorithms. In *Proceedings of the 8th Annual Conference on Genetic and Evolutionary Computation (GECCO '06)* (pp. 635-642). DOI:10.1145/1143997.1144112

### 2.4 지식 그래프 (Knowledge Graph)

**주장**: 지식 그래프(KG)는 개체와 관계를 삼중항(head-relation-tail)으로 표현한 구조화 지식 베이스로, 사용자-음식 섭취 이력을 KG로 인코딩하면 의미적 유사성 기반 개인화 추천이 가능하다.

**핵심 논리 흐름**:
1. KG 기본 개념 — 개체(entity)와 관계(relation)를 삼중항 형태로 표현. 예: `(사용자 A, 섭취했음, 된장찌개)`, `(된장찌개, 속함, SOUP)`, `(된장찌개, 식문화, 한식)`.

3. 본 연구의 KG 구조 — 사용자 섭취 이력 `(사용자, 섭취, 음식_i)`와 음식 노드별 선호도 가중치 `p_i`로 구성. KG는 매일 갱신되어 사용자 취향 변화를 f4 목적함수에 실시간으로 반영한다.
4. 차별점 — 본 연구의 KG는 정적 임베딩이 아닌 동적 갱신 구조로, 식문화 기반 초기화로 cold start를 해소하고 시간 감쇠로 반복 추천을 억제한다.

### 2.5 시간 감쇠 함수 (Time Decay)

**주장**: 지수 감쇠 함수를 도입하여 최근 섭취한 음식의 선호도 신호를 시간이 지남에 따라 약화시킴으로써, 반복 추천을 억제하고 식단 다양성을 확보한다.

**핵심 논리 흐름**:
1. 반복 추천 문제 — KG 선호도 점수만으로 추천하면 과거에 자주 먹은 음식이 계속 상위로 추천될 수 있다. 이는 단기 반복 섭취로 이어져 식단 다양성을 해친다.
2. 지수 감쇠 선택 이유 — 지수 감쇠 `D_time = exp(−λ · Δt)`는 (1) 반감기 해석이 직관적이고, (2) 연속 미분 가능하여 목적함수에 통합하기 적합하며, (3) 단기(Δt 작음) → 빠른 감쇠, 장기(Δt 큼) → 점진적 회복이라는 식습관 패턴과 부합한다.
3. λ=0.5 설계 의도 — 반감기 약 1.4일. 전날 섭취한 음식의 감쇠된 선호 점수가 원래의 약 60%가 됨. "이틀 연속 같은 음식을 먹고 싶지 않다"는 일반적 식습관을 반영한 설계 값이다.
4. KG 점수 통합 — `S_i = p_i · (1 − D_i)`. 선호도 가중치 `p_i`와 시간 감쇠 `D_i`를 결합한 최종 KG 점수가 f4의 입력이 된다. Δt_i가 클수록 D_i가 작아져 S_i가 커지고, 오래 전 섭취한 음식이 다시 추천 후보로 떠오른다.

**Forward-reference**: 시간 감쇠를 포함한 f4의 완전한 수식과 파라미터 근거는 Sec 4.2.4에서 기술되며, λ=0.5의 실험적 타당성은 Sec 6.5(7일 KG 시뮬레이션)에서 확인된다.

**그림**: 없음 (수식은 Sec 4.2.4의 `formula_kg_decay.png`에서만 배치)
- Sec 2.5에서는 인라인 수식 `D_time = exp(−λ · Δt)`, `S_i = p_i · (1 − D_i)` 텍스트로만 서술

**λ=0.5 설계 근거 명시**: 이론적 최적값이 아닌 설계 선택값임을 본문에 명시. 타 λ 값과의 비교 실험은 향후 과제로 남김(Sec 7).
